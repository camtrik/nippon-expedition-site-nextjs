## Magic · 巫女法系（完全原创）

法系规模对齐原版标准法系（6 法术＋1 学派被动），全部法术消耗魔法之风。每个法术节点**三级**（英雄版；领主版是两级，本法系现阶段只做英雄版），阶梯为固定模板：

| 等级 | 这一级给什么                                                                           |
| ---- | -------------------------------------------------------------------------------------- |
| Lv1  | 解锁基础施法                                                                           |
| Lv2  | 解锁增幅施法；该法术冷却 −30%（基础与增幅同降）                                        |
| Lv3  | 冷却 −50%（相对原始值，不与 Lv2 叠乘）；增幅版失误几率 −15%；魔风消耗 基础 −1／增幅 −2 |

增幅版不是独立一列，是 Lv2 才解锁的第二种施法模式，增幅数值写在 Lv2 行。**例外：『破魔矢』只有两级**——基础形态由隐藏 `magic_dummy` 在 1 级白送，可视节点直接从增幅起步（原版同款先例：墨衣诀；原版影岚诀同情形却仍做三级带 enable，不自洽，别抄它）。
