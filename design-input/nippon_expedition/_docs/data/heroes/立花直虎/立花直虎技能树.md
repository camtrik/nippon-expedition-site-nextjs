## 技能树总览

> `->` 前置推进；`-` 同层并行、全部可独立点出（不是互斥选项）；「需 N/M」= M 个并行父节点中至少点 N 个。

```text
特性（完全原创，2026-08-14 新建）：
  武士领袖（开局自带、固定不变）── 本地建筑费 −20% / 武士部队武器威力 +10%

Generic（孤立节点，陶炎收窄为 2 节点，原样复用）：
  魔法抗性 / 远程抗性

Combat（原样复制陶炎战斗分支，combat_3_3 换通用等价物）：
  剑术大师 -> 致命冲锋-全身板甲-躲闪腾挪-致命利刃 -> 索敌者（需 4/4）
  -> 杀伤猛士-疤面老兵-健步如飞-剑盾 -> 巨人一击（需 4/4）

Campaign（原样复制陶炎英雄战役行动，dummy 换自建）：
  campaign_01~06 + actions_dummy（自建）+ wh3_main_agent_action_scaling

Unique「个人专属线」（完全原创，剑豪／雷刃主题，拓扑同瑟兰娜）：
  二刀流（8 级解锁） -> 武士典范-铲奸除恶-雷神祝福-雷厉风行（并行，均需二刀流） -> 紫电一闪（capstone，点满 4 个后解锁，主动技能）
```

Node set 为 （内部标识）；unique 线与四条复用分支各自独立推进，互不阻塞。不设任何互斥锁。
