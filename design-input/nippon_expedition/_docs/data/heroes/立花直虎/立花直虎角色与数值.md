## 描述

『战鬼』立花直虎，雷神之女，双刀「紫电」的主人。敌人尚未看清她的身影，便已倒在雷光之下。

## 背景故事

立花直虎出身尼朋名门，是家中独女，年幼时便破例继承家督。少年时，她亲执双刀「紫电」，率旗本冲锋陷阵。尼朋内战爆发，立花家所属的阵营战败，领地被没收，直虎自此音讯不明。内战虽已完结，混沌势力仍在尼朋横行。相传有带着鬼面的少女手持双刀，出没于战火未熄的乡野。她的刀光快过视线，雷鸣随刀而至，被劈中的邪物焦黑如炭。

## 技能

### 被动技能

| 被动 | 生效形态 | 效果 |
| --- | --- | --- |
| 武士道 | 全部形态 | 生命值降至 50% 或以下时激活，残血期间常驻：基础／破甲武器杀伤 +15%、近战攻击 +10，并获得「永不败逃」 |
| 人剑合一 | 全部形态 | 常驻：近战攻击 +10、近战防御 +10；生命值低于 25% 时自动失效 |
| 地形适应 | 全部形态 | 仅身处森林时生效：护甲 +15、远程抗性 +20 |
| 英武必杀 | 全部形态 | 原版通用被动（引擎效果）：近战中有几率对单体目标一击必杀 |
| 狂暴 | 全部形态 | 原版通用被动：不计个人安危、狂热投入战斗（数值走引擎，无面板数据）。克隆模板遗留，是否移除待拍板 |
| 杀戮造诣指示 | 全部形态 | 黑暗精灵杀戮计数指示器，UI 隐藏不显示、对非黑暗精灵无效果。克隆模板遗留，是否移除待拍板 |
