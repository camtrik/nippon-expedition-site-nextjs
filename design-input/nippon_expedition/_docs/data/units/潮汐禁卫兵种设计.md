## 描述

玉海舰队的魔法战士无人可当，没几个人能在潮汐禁卫的刀锋下全身而退。

## 背景故事

沈长风亲统的嫡系禁卫，从玉海潮勇中百里挑一。她们持长柄刀、挎和弓，以震旦水师旧军的军纪驾驭尼朋的风浪。潮汐禁卫不挂任何大名家纹、也不打震旦皇室的龙旗——她们只认沈长风本人，「逆潮」提督的旗帜所指，便是她们挥刀的方向。每逢舰队的旗舰靠岸、敌阵当前，这些墨蓝甲衣的卫士总是最先列阵、最后撤离的一列；海风把她们的旗号吹得猎猎作响时，对手便知道，玉海舰队的提督今日亲自下场了。
