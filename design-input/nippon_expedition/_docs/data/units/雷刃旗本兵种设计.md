## 描述

大名直属的精锐武士，持雷神赐福的大太刀。刀身紫电缠绕，一挥可斩铁裂甲。

## 背景故事

旗本是武士中的武士。他们受大名直接统辖、世袭其位的近卫，非百战之功不得入列。所执的大太刀逾寻常太刀之长，须以双手挥舞，本是阵前斩马破甲的重器。其中一脉承雷神之契：相传昔日一位剑圣于雷暴之夜登峰参悟，以身试雷，引天火入刀，自此后人与门徒所持之刃皆具唤雷之能。刀出鞘时紫电自刃脊游走，挥斩之际雷光随刀锋迸裂；此非术士之法，而是以血肉之躯承雷霆、以剑技驭雷威的武道。旗本以剑技为根本，经年苦修，一刀之威已胜寻常武士数合，雷神之力不过为这极致剑技添上最后一道锋芒。两军阵前，见紫电破阵而来者，皆知旗本至矣。
