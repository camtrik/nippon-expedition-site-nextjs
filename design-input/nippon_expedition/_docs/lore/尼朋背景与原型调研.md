# 尼朋背景与原型调研

> 本文档整理战锤奇幻(Warhammer Fantasy)及《全战:战锤3》全部关于"尼朋"(Nippon,战锤世界对日本的映射)的官方/半官方/民间资料，作为本 MOD 世界观的地基。所有条目标注可信度：
> - 【官方-现行】Warhammer: The Old World / 全战3 等当前在售作品
> - 【官方-老旧】1-3版战锤奇幻等已停止支持的旧版规则书
> - 【民间】玩家考据/同人整理，未经 GW 官方确认
> - 【空白】检索后确认没有资料，可自由创作

> **本 MOD 现行加载屏引言（2026-08-23 定稿，已实装；本调研的世界观结论以此为准绳之一）：**
>
> 震旦往东渡过极东之海，便是武士之国尼朋。尼朋名义上共尊圣日朝廷，朝政却形同虚设，手握兵权的武士家族各自为政，大名之间为争夺将军之位，战事经年不休。而今，混沌的长船自寒雾中靠岸，异邦舰队窥伺海路，海盗、妖魔与野心家纷纷登上群岛。圣日的光辉仍照耀京都，但在列岛边陲，诸神、刀剑与野心已经一同出鞘。

## 1. 尼朋是什么

【官方-老旧/民间综合】尼朋是位于震旦以东、隔"极东之海"相望的一个庞大岛国，是战锤世界对封建日本的直接映射——包括直接沿用"武士(Samurai)"这类真实日语词汇。地理上，尼朋再往东是高等精灵的贸易据点"旭日之塔"(Tower of the Rising Sun)，再往东是"埃利希斯遗落群岛"(Lost Isles of Elithis)、龟岛(Turtle Isles)，然后是沸海(Boiling Sea)与纳垦罗斯。

**政体**：尼朋名义上由半神性质的"天照大御神/圣日"(Divine Sun)统治，但实权掌握在各自为政的武士领主手中，他们向治下农民收税、募集私兵，彼此间征战不休，圣日朝廷更多是一个仪式性的存在。**目前没有任何资料记载具体的幕府/朝代名称**，这是一块完全开放的创作空间。

**历史节点**(【官方-老旧】为主)：
- 尼朋在**雅玛九鬼一世(Yamyakyuki I)**治下首次统一，此人卒于帝历12年(12 IC)。此后尼朋反复陷入内战，但始终是远东最主要的文明。
- 约帝历前1400年：鼠人清道帮(Clan Eshin)的暗杀技艺据说习自尼朋(另有资料说习自震旦，两种说法并存，可信度存疑)。
- 帝历前87年：黑暗精灵黑方舟开始袭扰尼朋海岸——这是尼朋与黑暗精灵长期敌对关系的最早记录。
- 帝历2475年：马恩堡商人与尼朋正式建立联系，此后尼朋在马恩堡设有常驻使馆区"Nipponsstad"。
- **终末之战(End Times)**：兽人军阀葛力莫·钢铁颚(Grimgor Ironhide)攻破震旦长城后，在香江(Fragrant Harbour)劫持了一支兽人舰队，"由于缺乏方向感"而驶向离得最近的陆地——尼朋，并烧毁了尼朋的"守护龙舰队"。**这是目前印刷品中关于尼朋的最后一条时间线记录，此后尼朋的命运(存续/被征服/被摧毁)从未被交代**——这是本 MOD 最大的一块开放画布。

【官方-老旧】尼朋被反复描述为"对外人极度不信任"，罕有对外开放的先例；其樱花庭园被列为已知世界最美景致之一。武士道视战败为终极耻辱，个人名誉高于一切——这是各版本资料中唯一贯穿始终的文化主线。

**确认GW用过的东方神怪元素**：神风(作为战术概念)、忍术、僧兵武术流派、麒麟、狛犬。
**确认GW从未使用过的**：鬼(Oni)、河童(Kappa)、天狗(Tengu)、狐仙(Kitsune)——设定中的"龙"被明确归类为震旦的天龙一系，而非尼朋专属生物。**这四类若要用于本MOD，属于我方原创内容，没有GW先例可援引，但也没有任何官方设定与之冲突。**（本 MOD 神兽线现状：稻荷灵狐为原创采用、麒麟为 GW canon 直接采用并已实装，鬼(oni) 暂缓、河童/天狗/狐灵法师废弃，见 roadmap.md Phase 4）

## 4. 震旦与尼朋的关系

结论：**海上竞争对手 + 时断时续的贸易关系**，从未有过盟友、附庸或完全隔绝的记载，且各版本口径一致：

> 「东方，精灵海盗、尼朋侵略者，以及潜伏在玉海之下的远古敌人正侵扰着(震旦的)海岸。」
> —— 《战锤：旧世界》规则书 / 《奥秘期刊：震旦军团》，经 Lexicanum 转引

这是当前(2022-2024)最新的官方口径，**明确把尼朋和黑暗精灵海盗并列为震旦沿海的常态化威胁**，而非贸易伙伴。另有资料称震旦"不止一次与尼朋交战"，双方存在"经济竞争"，尼朋被称为"一个不容小觑的海上强权，即便在震旦天朝眼中也是如此"。

贸易方面：**长牙之路(Ivory Road，震旦对丝绸之路东段的称呼)**的记载路线经过世界之极山脉、黑暗之地、食人妖丘陵，直至印度、震旦，**乃至尼朋**——所以尼朋名义上是同一条贸易网络的东端终点之一，但没有具体的震旦-尼朋商队贸易细节记载；尼朋货物被描述为"偶尔出现在震旦港口的稀罕古玩"，会被辗转卖给旧世界商人。

> **结论对设计的意义**：所有资料指向同一个形状——**经济上是竞争对手、军事上是时断时续的海上宿敌，被同一条贸易路线松散连接，但谁都不完全掌控它**。没有任何盟友/藩属/友好关系的记载需要去推翻。**一支来自震旦、未经官方许可的私人武装在尼朋活动，恰恰是这种"官方渠道冰冷、灰色地带才走得通"局面的合理产物**——这直接支持了用户"倾向于非官方远征军"的设计取向。

## 5. "私兵团/非官方远征军"的原型依据

没有任何一个具名角色与这个设定完全吻合，但**有一段官方规则书原文几乎是量身定做**，外加一个具名角色提供了政治动机原型：

> 「武士领主有时会在座舰被台风吹散、漂流至异国海岸时游历海外，也有人是主动出海寻求冒险——尤其是在与国内敌对家族发生冲突之后。滞留海外时，他们通常会以雇佣军指挥官的身份提供服务，以换取给养与庇护。」
> —— 《战锤军队》(Warhammer Armies) 3版，第156页"武士领主"词条

这是整份调研中**最有用的一段文字**：它是官方、规则书正文，直接给出了一个可套用、不与任何设定冲突的起源模板——**一位在国内派系斗争中落败、或因风暴流落异乡的领主，选择不承认失败、不返回复命，转而成为一支不隶属任何朝廷的雇佣武装的指挥官**。

支持性旁证：
- **佐野·川崎**（见第2节）是"角色在设定内合法地脱离国家体制行动"的最清晰先例——他募集私兵、围攻本国都城，公然与朝廷政策对着干。把这个结构反过来用（一位领主*离开*尼朋，而非攻打尼朋，原因同样是与朝廷路线不合，或是在一场"川崎式"的路线斗争中站错了队）是直接对应的镜像写法。
- **马科斯·冯·卡斯坦**证明"非本地人物远赴尼朋游历、并带回一把名匠打造的佩刀、建立个人声望"这种叙事结构在设定中是被接受的（尽管他本人是吸血鬼，不能直接作为领主模板）。
- **Yin-Tuan**（震旦一侧的镜像案例）证明"因风暴漂流至陌生地界的船长"是设定中一个真实存在、哪怕次要的官方桥段。

**没有找到的**：无论是尼朋还是震旦一侧，都没有具名的"落魄提督""海盗领主""冒险商人"角色模板。"私人远征"这个概念**不是以角色的形式预先存在，而是以一条规则的形式预先存在**——这意味着我们不是在推翻某个具名角色，而是在填补一个规则书明确说"这种情况很常见、不值得大惊小怪"的空位。这是非常扎实的创作基础。

## 6. 全战3的具体情况

- **尼朋从未出现在全战3中**——无论是本体、"变革之影"(4.2版本)还是其后的震旦相关更新，均无任何加载画面文本、任务战文本、单位或具名角色涉及尼朋。玩家社区讨论明确将尼朋定性为"目前不在游戏中……被视为一个没有军队名单或实际官方设定的背景文明"。
- 震旦的**战役地图在"东方省"(Eastern Provinces)处到达边界**，由传奇领主**吟吟(Yin-Yin)，玉海之龙、玉海之主**统治（本 mod 内定名为「溟龙胤隐」，见 `沧溟巨炮兵种设计.md` 与胤隐兼容包文案）——这是CA实际做出的最靠东的可游玩震旦领土。不存在可探索的"东方群岛"区域，也没有找到"镜月"(Mirrored Moon)这个说法在任何官方资料中的出处，可能是与"渊石沙漠的镜盾"或震旦对月亮的称呼"月印(Yueyin)"混淆，**若该设定需要成立，建议不要采用，或视为纯原创设定**。
- **长牙之路(Ivory Road)**是震旦在全战3中的核心经济机制，是丝绸之路的游戏内对应物，文字设定上通向印度与尼朋方向——但游戏实际的商队路线只在震旦自身定居点与部分非震旦阵营之间往返，**尼朋从未是可选的商队目的地**。

> **实际意义**：正因为CA从未触碰过尼朋，一个基于震旦模板的MOD**不存在与全战3已发行内容冲突的风险**，唯一需要兼顾连续性的是1-3版桌游时代留下的这些老旧片段（第1-4节）。CA的沉默本身就很能说明问题——尼朋被有意留作地图边缘之外的一块"未认领叙事领土"，而"私人远征"这个前提——从地图边缘出发、脱离震旦朝廷管辖、也不被尼朋朝廷承认——恰好是最适合去讲这个空白故事的角度。

## 7. 创作自由度小结

**已有依据、不建议随意更改的**：尼朋的基本身份（孤立主义封建日本映射、圣日/武士二元权力结构、与震旦的竞争对手关系、长牙之路终点之一）、第3节的兵种清单、第5节"游历在外的武士领主转职雇佣军指挥官"这一叙事机制。

**完全开放、可自由创作的**：幕府/朝代命名、具体的藩国/大名政治格局、鬼/河童/天狗/狐仙相关的具体设定、尼朋都城之名（现已定为「京都」，2026-08-23 加载文案起用）、当代"圣日"的身份，以及——最重要的——**终末之战之后尼朋整个国家的存续状态（幸存/被兽人征服/介于两者之间），这一点至今没有任何印刷品给出答案**，可作为本战役叙事的核心悬念之一。
