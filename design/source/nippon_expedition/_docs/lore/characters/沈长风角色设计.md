## 1. 性格设计

沈长风的性格从02文档已定案的背景直接推导，不做多方案——她的经历本身已经决定了性格的核心矛盾，不需要另外发明。

**核心矛盾：仍是震旦军人，却不再为震旦效力。** 她没有"背叛者"的自我认知——在她自己的叙事里，越界追击是正确的军事判断，朝廷的问罪才是政治怯懦的表现。这种"我没错，是体制配不上我的判断"的心态，让她对震旦官僚系统保持轻蔑，却始终保留着震旦水师的纪律做派、指挥习惯、甚至审美——旗舰内务、队列训练、军法执行，全套搬到了这支"无冕之师"身上。这不是怀旧，而是她唯一会用的语言。

**具体性格特质：**

- **果决近乎冒进**：擅自越界追击并不是一时冲动，而是她一贯的决策模式——认定目标之后不等上级批复、不留退路。这条特质已经在02文档"阴/阳选择：阳系(Yang)"的flavor拍板里被确认（`_docs/data/领主与阵营配置.md` 第51行），本文档只是把它落到性格描述上。放在游戏机制上，可以对应"合法性/独立性"双轴中偏"独立性"一端的直觉倾向，但她本人未必是路线A/B的坚定信徒——她是被处境推着走，而不是有清晰的政治理想。
- **对新征服/收编力量保持克制的疏离**：她不寻求尼朋任何一方的认可，也不轻易向新归附者交心——她要建立的是自己的秩序，不是讨好任何一方，多年行伍生涯教会她"承诺要用行动兑现，不是靠嘴上示好"。这不等于冷漠，而是一种刻意维持的距离感：她会公平对待麾下部队、兑现给出的条件，但信任要靠长期共事换取，不是加入的第一天就能拿到的。立花直虎、纱代、瑟兰娜这类后加入的角色如果想真正进入她的信任圈，需要用行动而非言语证明。
- **认同与决裂的双重张力（贯穿全程，不要提前解决）**：她嘴上瞧不起朝廷，行动上却始终用震旦的标准要求自己和部队——这个矛盾不应该在早期剧情就被"治愈"或"选边"，而应该保留到路线A/B分支才真正摊牌。技能树（2.0.3，已明确推迟）如果未来要做"合法性"分支的专属天赋，可以直接挂在这条张力上。
- **可用于台词/任务链的性格细节**：
  1. 她厌恶被称为"海盗"或"流寇"，即使部队实际行为（劫掠、保护费、强征补给）和海盗别无二致——她坚持自己是在收拾一片乱局、开辟秩序，而不是趁乱打劫，语言上的坚持是她仅剩的体面。
  2. 她唯才是用，不看出身门第。这种震旦式实用主义和尼朋本地武士文化（重名誉、重门第）天然错位——既可能冒犯对方，也可能让被门第压住的人感到被公正地对待，具体走向可以留给立花直虎的剧情线决定。

## 2. 外貌设计（已定案，2026-07-18）

**已从三个候选方案中定案**：以原方案B（震旦骨架+尼朋甲胄对半混搭）为基础，但做以下修正——不采用"混血提督"这个方案名；发型保留原方案A的高单马尾结构但发色改为银灰；不设旧伤疤；标志性武器改为一把从尼朋缴获的名刀，不做双持。锁定的既定元素为：**钢蓝(`285898`)+旧金(`B89245`)配色，少量碧玉绿(`1F8A70`)点缀**、震旦水师官服底子、"阳系"果决气质。

### 已定案外貌：震旦骨架 + 尼朋甲胄对半，双持震旦制枪「镇澜」与缴获名刀「逆潮」

- **体型气质**：中等偏高身量，披挂较重、带一点甲片碰撞的分量感——这是"提督"这个称号该有的仪式重量，但撑起这份重量的是她扛得住这身甲胄的体格与气场，不是头衔本身。
- **发型发色**：银灰色高单马尾，发色应落在偏冷的中性银灰区间（约 `9EA7AA` 至 `B7BEC0`），保留足够灰度阴影，避免读成纯白、铂金金发或发光魔法发；发型仍是震旦水师制式的高束发，不做尼朋式发髻——即使铠甲已经开始"混搭"，发型结构仍然是她拒绝被同化的最后一道防线，视觉上呼应她"仍是震旦军人"这条核心矛盾（见第1节）。银灰发承担传奇领主的远读辨识度，但不能把气质推向仙气或纯法师化。
- **面部气质**：眉眼锐利、表情克制，年龄感维持30岁上下；不设旧伤疤——她的凌厉感来自气场而非伤痕，不需要靠外显的疤痕讲故事。
- **铠甲/军服形制与配色**：上半身保留震旦水师官服的立领/披风轮廓，下半身与护具改用尼朋当世具足风格的札甲片，两种甲片体系在腰际做一个明显的过渡带（系带或半月形腰甲，视觉上"缝合"两种风格）。大面积布料与甲片统一使用钢蓝 `#285898`（暗部由该色加深处理，不再单列独立 hex），旧金 `#B89245` 用于尼朋甲片镶边、腰扣、护腕、靴甲和家纹式肩甲纹样（用玉海舰队的旗号图案代替真实尼朋家纹），亮金 `#D4AF37` 只作为磨损高光。碧玉绿 `#1F8A70` 仅可用于胸前宝石、腰带嵌饰、绳结或刀鞘小点缀，不再铺在主布料上。
- **标志性道具·「逆潮」**：在尼朋海岸的一场战斗中缴获的名刀「逆潮」。"逆潮"取"逆流而行"之意，双关她本人的处境——呼应她"擅自越界追击、拒绝朝廷问罪"这条逆流而上的人生轨迹。这把刀是MOD原创虚构兵刃，不是真实历史文物；命名风格参考真实历史太刀的命名传统（如数珠丸、鬼丸国綱、石切丸、鶴丸国永），但不照搬。也可以设计成一件与05文档"佐野氏(Sanyo Clan)"——本MOD开局阶段最主要的内战对手——直接绑定的战利品：传说是佐野氏世代相传的家宝，锻造年代已不可考，家臣间流传着一则与佐野氏先祖"抗命朝廷"有关的旧传说（呼应01文档记载的佐野·川崎"因朝廷未攻击外国船只而募私兵围城"这段官方老旧设定，但不直接断言两者是同一人/同一时期，留有解释空间）。刀鞘漆面沿用个人外观配色重新髹涂——钢蓝打底、旧金浪线勾勒，可点缀少量碧玉绿嵌饰，是她把这件战利品"收归己有"的最直观视觉标志，也是一个现成的任务链/对话钩子：残存的佐野旧部看到自家祖传名刀挂在这个外来者腰间会作何反应，可以留给具体任务链设计阶段展开（是否真的绑定佐野氏叙事仍是开放项，见第4节）。
- **标志性道具·「镇澜」**：沈长风另一手持一杆震旦水师制式长枪「镇澜」。与缴获的尼朋名刀「逆潮」不同，「镇澜」是她自震旦水师带出的旧制佩枪，未曾改易——这是她身上唯一一件完全没有"异乡"痕迹的标志，对应第1节"仍是震旦军人，却不再为震旦效力"的核心矛盾：如果说银灰高马尾是她拒绝被同化的最后一道防线（见发型发色条），那么「镇澜」就是那道防线握在手里的实物。「镇澜」字面是"镇平海波"的水师军号（呼应她"玉海舰队提督"的身份），与「逆潮」恰好构成一组对照——「镇澜」的"镇"是震旦制式的服从与秩序，「逆潮」的"逆"是越界与抗争，一镇一逆，把她对"潮"（命运、朝廷、异乡）的两种姿态分攥在左右两手，也是她整个人生矛盾的具象缩写。命名走震旦水师军号/诗意传统，刻意区别于「逆潮」参照的日式太刀命名传统——两把兵器的命名文化对照本身就在强化"震旦 vs 尼朋""故土旧制 vs 异乡战利品"这层张力。这杆枪是MOD原创虚构兵刃，不是真实历史文物。具体武器资产（枪头形制、枪杆配色与「逆潮」刀鞘的配色统一关系、双持武器 slot 接入）留给 AssetEditor 建模阶段处理，本文档只锁定叙事与命名。
- **Kitbash 素材方向**：铠甲部分沿用原方案B的判断——震旦骨架部件与尼朋风格甲片需要分别取材再拼合，甲片部分可参照 [`雷刃旗本兵种设计.md`](../../data/units/雷刃旗本兵种设计.md) 等武士线兵种的既定尼朋美术语言；发型部分沿用原方案A的判断，从其他阵营的女性人形部件里找一个利落的高马尾头部（震旦自身没有可用的女性战场级部件，见 `tutorial/03` 第8.1节结论）。「逆潮」作为独立的武器prop，需要单独kitbash一把尼朋太刀形制的武器资产并接入 ancillary/prop slot，不能直接沿用震旦制式武器模型。

### 展示资产的构图边界（2026-07-18）

- **肖像**：指兵牌与阵营选择界面所用的头肩近景，而非全身角色图。小尺寸下优先保证锐利眉眼、银灰高单马尾、钢蓝立领与一侧旧金尼朋肩甲的辨识度；不戴头盔、冠冕或面具，以呼应“无冕提督”，仅在发根保留一枚低调的金色舰首/浪纹发簪。脸部三分之二侧向画面左侧，视线略越过镜头望向右前方，体现冷静的判断力而非怒视。背景定为暗赤、近黑的风暴天幕，后方仅留模糊的金属色舰桅与绳索，不出现火焰、城市或敌军；以暗赤托出银灰发与深蓝立领。「逆潮」最多只露出刀柄或鞘口，不承担主要识别职责。
- **渲染风格**：肖像遵循战锤 UI 的半写实厚涂语言——近景裁切、强烈明暗、低饱和暗部与可见的金属磨损/布料风化；拒绝干净的日系赛璐璐、时尚海报或扁平图标感。
- **立绘**：独立的全身人物图，可完整呈现震旦水师上装、尼朋札甲、腰际过渡带与「逆潮」。场景固定为旗舰前甲板：湿润的深色船板、远处翻涌的玉海、半收的帆与一角玉海舰队旗帜受风。默认姿态定为“压住风浪的指挥官”：三分之二侧身、望向画面前方，右手自然压在刀鞘上，披风与单马尾受海风推向一侧；不是拔刀或挥砍姿势。光源为暴风云缝落下的一束冷光，仅局部点亮金色甲边。
