## 1. 背景设计

### 1.1 展开原则

**留白原则不变**：流浪（成为浪人）之前与之中的具体经历——家系名称、领地位置、行侠阶段铲奸除恶的具体对象——不在本文档钉死，留给后续任务链逐步揭示，现在只锚定不能反悔的骨架。但 2026-08-13 调整后，骨架本身比原先重了一档：她不只是"一名女性剑豪"，而是**率旗本征战过的剑豪当主、剑技通神而获雷刃之力**——这三条是新钉死的核心身份，其余细节仍走留白。这与沈长风"认同与决裂的双重张力，贯穿全程、不要提前解决"的设计原则（见 [`沈长风角色设计.md`](./沈长风角色设计.md) 第21行）是同一种做法：钉骨架、留弹性。

### 1.2 现在锚定的最小背景框架

- 她出身尼朋一个**有实力豢养旗本的家系**（暂不命名）——家中无男嗣，她年少破例继承家督，是名正言顺的女性当主。她不只是坐镇的主君，更是亲提双刀、率自家旗本冲锋陷阵的**剑豪大将**。
- 她剑术通神，由此触到了**雷刃之力**——雷刃之力是"剑技臻于化境即可引天火入刃"的武道法则，广泛可学，与出身、门第、师承无关；旗本所执的大太刀是这条路最常见的形制，她以**双刀**「紫电」达到同境。雷刃之力随着她的剑技一起留了下来。
- 尼朋内战中她家系**战败**，领地被没收，旗本或死散或被收编，她独力杀出。
- 此后尼朋仍战火不绝——混沌、绿皮等势力肆虐地方。她**隐姓埋名**流落民间，在乡野铲奸除恶、护佑百姓，以双刀与雷刃之力立身，"剑豪"之名由此而来。
- 她是第一个投效沈长风的本地武士。

> 双刀定名「紫电」，两刀共用一名（2026-08-13 定）。

### 1.3 与沈长风的连接点（可直接使用，不算过度深挖）

直虎隐姓埋名在民间行走多年，看人看的是两件事：**能不能打、肯不肯护民**。她在乡野见过太多空有名分却无力护佑一方的"主君"，自己也曾是那样的当主、也那样失去了一切。沈长风是她难得觉得对得上的人——一个真在做事、真在远征守土的人，而不是徒有名分之辈。具体台词方向留给深入设计阶段，这里只锚定逻辑：她的投效不是因为被赏识、被收留，而是因为遇到了同道。

### 1.4 明确留白、留给任务链的开放项

- 原家系的具体名称、领地位置，是否与已确立的尼朋内战阵营（佐野氏/奥本氏等）有直接交手关系——沈长风的佩刀「逆潮」也留了类似的"是否绑定佐野氏"开放项（[`沈长风角色设计.md`](./沈长风角色设计.md) 第71行），两者可以联动决定，也可以各自独立处理。
- 隐姓埋名行侠阶段的具体经历、铲奸除恶的对象（具体的混沌/绿皮/地方恶霸？），留白给任务链。
- 誾千代故事里"入赘丈夫与名义当主权力错位"这层关系，**不采用**——用户只确认了"女性当主 + 战败失势"这条弧线，没有确认要不要一个对应的丈夫/同伴角色。如果未来任务链需要一个"曾经的同伴/丈夫"角色制造戏剧张力，需要单独拍板。
- 战败发生在她投效沈长风之前多久、之间她具体经历了什么，都留白。

## 2. 玩法定位（继承自02文档，不改变）

近战突击向英雄，**双刀流**，象征"本地武力归附"主线，可经远征同伴面板以名望征召武士线兵种（长枪武士／铁炮武士／雷刃旗本，见 [`data/units/`](../../data/units/README.md) 与 [立花直虎角色与数值.md](../../data/heroes/立花直虎/立花直虎角色与数值.md)）。第一个投效沈长风的本地武士，这个"第一个"的顺位本身也是她剧情线的天然锚点——后续如果要写"其他本地势力观望她的选择再决定态度"这类支线，可以直接挂在这个设定上。

## 4a. 外貌方案（2026-07-31 定案）

核心原则：视觉上刻意**避开**任何还残留"当主"身份感的东西，与沈长风"仍有制服感的震旦水师军官"路线形成对照——她的主线情绪是"名分被夺、只信手中刀"，不是"落魄贵族"。

- **主色系**：褪色藍染 `#3A4A5C` 搭铁灰 `#5C5850` 作为浪人旅装底色——藍染是历史上浪人/下级武士常见的实用染色，褪色感呼应"失去了家系该有的锦绣"。局部用暗赭红/干血色 `#6B3A2E` 点缀破损处、绑绳与护手，暗示剑豪身份里的杀伐气。**刻意不用金色**——旧金 `#B89245` 是沈长风"仍认自己是水师军官"的专属信号，直虎不应共享这层身份符号。
- **服装形制**：不穿成套甲胄，半身轻装——小袖/胴着，配缚起的挂绳（襷掛け）方便双刀挥砍；肩甲最多单侧一块残破札甲护肩，暗示"曾经有过完整的家系甲胄、如今只剩一片"；下身裁短裁付袴便于步战；草鞋或胫甲带磨损感。整体轮廓比沈长风"单持佩刀+完整披风"更精简、更破旧、更"轻装亡命"，一眼能读出"浪人"而非"落魄贵族"。
- **鬼面**：江湖传说"带着鬼面的少女"的视觉符号（对应实装专属装备「鬼面」，见 鬼面.md），可挂腰间或作半脸面具，与褪色蓝染浪人装同属"隐姓埋名"的意象；具体呈现留给美术阶段。
